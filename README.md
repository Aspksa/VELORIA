# VELORIA — Живой мир v0.3.0

Автономная браузерная пиксельная симуляция. Откройте `index.html` (интернет не нужен).

## Управление
WASD / стрелки — перемещение камеры, колесо — масштаб, перетаскивание — панорамирование, клик — осмотр жителя. Пауза, скорость, сохранение и новый мир доступны на панели.

## Когнитивный прототип
Каждый житель хранит ограниченную индивидуальную память, формулирует проверяемые гипотезы о добыче, проводит реальные рабочие попытки, оценивает успех, обновляет убеждения, делится опытом с соседями и самостоятельно меняет профессию при дефиците ресурсов. Эти процессы влияют на добычу и действия NPC.

**Ограничение:** это зачаток экспериментального поведения, а не универсальный интеллект. Гипотезы пока ограничены добычей и экономическими потребностями. Мосты, корабли, новые материалы, свободные изобретения и LLM пока не реализованы.

## Сохранения
Используется ключ `veloria-save-v3` в localStorage браузера. Старое сохранение v2 не импортируется автоматически. `Новый мир` заменяет текущий слот после подтверждения.

## Технология
Vanilla JavaScript + Canvas2D; никаких облачных ключей или внешних зависимостей.
